# Python-Day15

We've implemented a quiz simulator using object-oriented programming. Observe the separate Question and QuizBrain classes and the way they've been used in our main.py file.

To run this code, ensure that the following files are in your working directory:

1. main.py
2. data.py
3. question_model.py
4. quiz_brain.py

In your terminal, run the quiz using the command "python main.py" and enjoy!
